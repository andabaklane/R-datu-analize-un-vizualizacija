# Ievads R un datu vizualizācijā

Materiāli nodarbībai par datu analīzi un vizualizāciju R vidē.

## Projekta saturs

- `tulkojumu_datu_stasts.qmd` — nodarbībā izmantotā koda burtnīca
- `r_macibu_vardnica.html` — R un ggplot2 mācību vārdnīca
- `patstavigais_darbs_promocijas_darbi.qmd` — patstāvīgā darba sagatave
- `data/` — nodarbībā izmantotie dati

## Kā sākt darbu

1. Uzinstalē R https://cran.r-project.org/bin/windows/base/
2. Uzinstalē RStudio Desktop https://posit.co/downloads
3. Lejupielādē visu projekta mapi no GitHub.
4. Atarhivē ZIP failu savā datorā.
5. Atver projekta mapi.
6. Veic dubultklikšķi uz `01_ievads_R.Rproj`.

Tiks atvērts RStudio ar pareizi iestatītu projekta darba mapi.

## Nodarbības materiāls

Atver `tulkojumu_datu_stasts.qmd`.

Koda šūnas vari izpildīt pa vienai RStudio vidē. Visa dokumenta HTML versiju vari izveidot ar **Render**.

## Patstāvīgais darbs

Atver `patstavigais_darbs_promocijas_darbi.qmd`.

Izmanto failu `data/promocijas-darbi.csv`, lai izveidotu savu datu stāstu.

Šajā uzdevumā drīkst izmantot valodas modeli kā konsultantu R koda
veidošanai, kļūdu skaidrošanai un vizualizāciju apspriešanai.

Darba rezultāts: Quarto dokuments un no tā izveidots HTML datu stāsts.
